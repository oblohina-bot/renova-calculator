# RENOVA — калькулятор вартості ремонту

Навчальний проєкт: калькулятор орієнтовної вартості ремонту квартири в Україні.
HTML5 + CSS3 + Vanilla JavaScript в одному файлі `index.html`, тарифи — у `prices.json`.

## Локальний запуск

`index.html` читає `prices.json` через `fetch()`, а браузери блокують це для сторінок,
відкритих як файл (`file://`). Тому сторінку треба відкривати через локальний HTTP-сервер.

У терміналі перейдіть у папку проєкту й запустіть один із варіантів:

```bash
python3 -m http.server 8000
```

```bash
ruby -run -e httpd . -p 8000
```

Потім відкрийте в браузері: http://localhost:8000

## Тарифи

Тарифи за м², коефіцієнти терміновості та умови знижки зберігаються в `prices.json`.
Це демонстраційні значення, а не підтверджені ринкові ціни.

Формула:

- `базова вартість = площа × тариф за м² × коефіцієнт терміновості`;
- для площі строго понад 100 м² діє знижка 10% (для рівно 100 м² — без знижки);
- `підсумок = базова вартість − знижка`.

## Можливості

- синхронізовані поле площі та слайдер, автоматичний перерахунок;
- картки типів ремонту й вибір терміновості;
- деталізація формули, окремий рядок знижки та бейдж економії;
- порівняння вартості трьох типів ремонту (CSS-діаграма, кожен варіант можна обрати);
- копіювання розрахунку в буфер обміну;
- друк / «Зберегти як PDF» через `window.print()` зі світлим кошторисом A4;
- скидання параметрів до початкових значень.
