# RENOVA — калькулятор вартості ремонту

Навчальний проєкт: калькулятор орієнтовної вартості ремонту квартири в Україні.
HTML5 + CSS3 + Vanilla JavaScript в одному файлі `index.html`, тарифи — у `prices.json`.

## Локальний запуск

`index.html` читає `prices.json` через `fetch()`, а браузери блокують це для сторінок,
відкритих як файл (`file://`). Тому сторінку треба відкривати через локальний HTTP-сервер.

У терміналі перейдіть у папку проєкту й запустіть один із варіантів:

```bash
python3 -m http.server 8000
```

```bash
ruby -run -e httpd . -p 8000
```

Потім відкрийте в браузері: http://localhost:8000

## Тарифи

Тарифи за м² і коефіцієнти терміновості зберігаються в `prices.json`.
Це демонстраційні значення, а не підтверджені ринкові ціни.

Формула: `площа × тариф за м² × коефіцієнт терміновості`.
